# Nine-Week Java Assignments

Solutions for the 45 Java programming assignments across Weeks 1–9.

## Structure

Each week has five standalone Java programs. Each source file uses its own unique class name and contains a `main` method where a complete program is expected.

- `Week-01`: strings, nested loops, streaks, inventory totals
- `Week-02`: string validation, word processing, CSV parsing, frequency counting
- `Week-03`: classes, objects, constructors, static and instance members
- `Week-04`: array algorithms and prefix sums
- `Week-05`: arrays, methods, 2D arrays, sorting/comparable
- `Week-06`: constructors, encapsulation, static members and references
- `Week-07`: encapsulation and defensive programming
- `Week-08`: polymorphic billing, parking, electricity, bonuses and renewals
- `Week-09`: ticketing, shipping, college fees, cab fares and appliance usage

## Compile and run

Open a terminal in the folder containing the Java file. For example:

```bash
javac Week01Problem01.java
java Week01Problem01
```

Read each assignment's comments and prompt carefully. Input-driven programs read from standard input unless their prompt says otherwise.

## Notes

These are learning solutions intended to make the key logic and object-oriented concepts easy to inspect. Always compare output formatting with the exact requirements provided by your course before submission.
